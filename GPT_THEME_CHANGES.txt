GPT 网页中性色主题改造说明

本次直接修改上传项目的源码，采用 GPT 网页风格的白色主区、浅灰侧栏、深灰主按钮与灰阶图表。属于近似视觉风格，并非 ChatGPT 官方 CSS。

调整：
- 去除绿色品牌强调和纹理背景。
- 侧栏 208px、导航行 36px、顶栏 52px。
- 正文 13px、标题 18px，表格和卡片收紧间距。
- 登录面板宽 360px，窄屏适配并保留键盘焦点反馈。
- 警告和错误仍使用低饱和橙、红，状态标签和文字保留。

验证：vue-tsc --noEmit 和 Vite 生产构建通过；构建仍提示原有大体积 JS 分块。已使用模拟数据完成看板在 1440 / 1024 / 768 / 390px 宽度的浏览器布局检查；页面无横向溢出。注册页统计 2x2，堆叠卡片间距 12px。未验证真实 WhatsApp 连接或发送。

使用：解压到新的目录，在 frontend 下执行 npm install，再执行 npm run dev。生产构建执行 npm run build；更新后的 frontend/dist 已包含。前端运行无需 Docker，后端启动方式沿用原项目 README。上传包原有依赖、配置及其他文件均保留。
