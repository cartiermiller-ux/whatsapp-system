卡片布局修正

- 看板使用统一栅格：今日概览，快捷操作 + 通道状态，任务表，账号健康度。
- 并排卡片等高，外间距统一为 12px。
- 指标卡固定 4 / 2 / 1 列，避免 3+1 和八列过窄。
- 注册状态四卡固定 2x2；双栏页面在中窄屏堆叠，补上纵向间距。
- 通道长名称换行，健康度标题换行，图表使用 ResizeObserver 响应展开和侧栏变化。
- 浏览器检查：1440 / 1024 / 768 / 390px 看板无页面横向溢出，展开健康度后 canvas 正常绘制。注册页堆叠间距 12px。使用模拟数据，未连接真实 WhatsApp 服务。
- Vue 类型检查及 Vite 生产构建通过；仍有原有大型 JS 分块提示。

直接解压使用新项目，frontend 下运行 npm install、npm run dev；dist 也已更新。GitHub 尚未提交。
