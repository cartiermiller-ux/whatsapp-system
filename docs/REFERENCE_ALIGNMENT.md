## 专用协议缺口

补充检查：参考站点五段扫码号表单要求上传 ZIP；全参号 v0 接受 TXT/JSONL，v1 另支持 ZIP；账号导出提供频道号文本或 JSON。直登号表单从账号分组生成序列号，工具下载区提供多开应用版及需 root 的原生应用版。已检查的表单、提示和前端请求仅描述文件类型、版本及上传地址，没有给出五字段名称、顺序或逐条 JSON 示例。因此不能根据这些页面认定文件与本系统会话 ZIP 兼容；后续需要核实实际文件格式，不限定必须提供供应商 API 文档。

参考账号新建支持个人/商业、安卓/IOS、六段频道、五段扫码、频道号；直登号管理支持生成并导出设备序列号。以上依赖参考服务的协议登录、账号检测或客户端工具，浏览前端不能证明协议兼容。本系统当前连接引擎是 Baileys 关联设备会话，不能将手机私有协议全参、五字段或参考序列号转换成可登录会话。用户确认没有供应商文档；这部分保持明确缺口，不伪造登录、解风控或直登能力。

完整会话 ZIP 导入仅接受本系统格式 `baileys-multi-file-auth` 版本 1，验证手机号及密钥文件，拒绝重复账号、不安全路径、重复路径和过大压缩包。导入默认不连接，必须由用户执行连接并验证。
