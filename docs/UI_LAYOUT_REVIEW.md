# 页面布局与工作流程调整

保留现有 12 个业务路由，采用 GPT 网页的中性白灰配色和紧凑密度。

| 页面 | 主方向与调整 |
| --- | --- |
| 数据看板 | 概览 → 最近任务 → 对接状态；移除独立快捷操作卡片，新建群发放到任务区 |
| 号码池管理 | 筛选与列表；删除只在选中号码后出现 |
| 注册管理 | 注册进度与结果；批量注册通过顶部按钮打开抽屉；成功率只显示一次 |
| 账号管理 | 完整宽度的账号列表；账号状态分布收进折叠区，取消独立侧栏图表 |
| 资源群管理 | 筛选与列表；获取链接在选择群后出现；移除未实现的操作按钮 |
| 群发任务 | 默认显示任务列表，顶部按钮打开创建抽屉；高级未开放选项折叠 |
| 拉群任务 | 默认显示任务列表，顶部按钮打开创建抽屉 |
| 资源对接 | 保留按供应商、代理、接码、采购分组的标签页，统一布局 |
| 广告消息管理 | 文案与超链各有一个创建入口，移除无效 AI 生成入口 |
| 余额与计费 | 概览 + 资金流水 / 充值订单 / 计费规则；账户充值使用抽屉 |
| 个人中心 | 账号资料 / 安全设置 / 操作记录分别展示 |
| 系统设置 | 参数按类别折叠；保留全局保存、权限限制与其他管理标签页 |

## 页面切换与响应式

切换路由后主内容滚动到顶部；缓存的拉群页不会响应群发创建参数。
统一表单、卡片、间距、分页与窄屏抽屉。桌面、平板、手机检查宽度为 1440 / 1024 / 768 / 390px。
